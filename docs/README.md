# Geometric Lib

Данный проект представляет собой библиотеку на языке Python, предназначенную для вычисления основных геометрических параметров (площади и периметра) для плоских фигур.

---

## Общее описание решения

Библиотека содержит четыре основных модуля:
- **`circle.py`** - функции для вычисления параметров круга (площадь, длина окружности).
- **`rectangle.py`** - функции для работы с прямоугольником (площадь, периметр).
- **`square.py`** - функции для работы с квадратом (площадь, периметр).
- **`triangle.py`** - функции для работы с треугольником (площадь по стороне и высоте, периметр по трем сторонам).

---

## Описание функций с примерами вызова

### Модуль `circle.py` (Круг)

Предоставляет функции для работы с кругом и окружностью. Для расчетов используется значение $\pi$ из стандартной библиотеки `math`.
#### `area(r)`
* **Описание:** Вычисляет площадь круга по заданному радиусу.
* **Математическая формула:** $S = \pi \cdot r^2$
* **Параметры:**
  * `r` (`int` | `float`) - радиус круга.
* **Возвращаемое значение:**
  * `float` - площадь круга.
* **Пример вызова:**
  ```python
  import circle

  s = circle.area(5)
  print(s)  # Выведет: 78.53981633974483
  ```

#### `perimeter(r)`
* **Описание:** Вычисляет периметр (длину окружности) круга по заданному радиусу.
* **Математическая формула:** $P = 2 \cdot \pi \cdot r$
* **Параметры:**
  * `r` (`int` | `float`) - радиус круга.
* **Возвращаемое значение:**
  * `float` - длина окружности.
* **Пример вызова:**
  ```python
  import circle

  p = circle.perimeter(5)
  print(p)  # Выведет: 31.41592653589793
  ```

### Модуль `rectangle.py` (Прямоугольник)

Предоставляет функции для работы с прямоугольником по длине двух смежных сторон.

#### `area(a, b)`
* **Описание:** Вычисляет площадь прямоугольника по двум сторонам.
* **Математическая формула:** $S = a \cdot b$
* **Параметры:**
  * `a` (`int` | `float`) - длина первой стороны.
  * `b` (`int` | `float`) - длина второй стороны.
* **Возвращаемое значение:**
  * `int` | `float` - площадь прямоугольника.
* **Пример вызова:**
  ```python
  import rectangle

  s = rectangle.area(3, 4)
  print(s)  # Выведет: 12
  ```

#### `perimeter(a, b)`
* **Описание:** Вычисляет периметр прямоугольника по двум сторонам.
* **Математическая формула:** $P = 2 \cdot (a + b)$
* **Параметры:**
  * `a` (`int` | `float`) - длина первой стороны.
  * `b` (`int` | `float`) - длина второй стороны.
* **Возвращаемое значение:**
  * `int` | `float` - периметр прямоугольника.
* **Пример вызова:**
  ```python
  import rectangle

  p = rectangle.perimeter(3, 4)
  print(p)  # Выведет: 14
  ```

### Модуль `square.py` (Квадрат)

Предоставляет функции для работы с квадратом по длине его стороны.

#### `area(a)`
* **Описание:** Вычисляет площадь квадрата по его стороне.
* **Математическая формула:** $S = a^2$
* **Параметры:**
  * `a` (`int` | `float`) - длина стороны квадрата.
* **Возвращаемое значение:**
  * `int` | `float` - площадь квадрата.
* **Пример вызова:**
  ```python
  import square

  s = square.area(5)
  print(s)  # Выведет: 25
  ```

#### `perimeter(a)`
* **Описание:** Вычисляет периметр квадрата по его стороне.
* **Математическая формула:** $P = 4 \cdot a$
* **Параметры:**
  * `a` (`int` | `float`) - длина стороны квадрата.
* **Возвращаемое значение:**
  * `int` | `float` - периметр квадрата.
* **Пример вызова:**
  ```python
  import square

  p = square.perimeter(5)
  print(p)  # Выведет: 20
  ```

### Модуль `triangle.py` (Треугольник)

Предоставляет функции для работы с произвольным треугольником.

#### `area(a, h)`
* **Описание:** Вычисляет площадь треугольника по стороне и проведенной к ней высоте.
* **Математическая формула:** $S = \frac{1}{2} \cdot a \cdot h$
* **Параметры:**
  * `a` (`int` | `float`) - сторона (основание) треугольника.
  * `h` (`int` | `float`) - высота, опущенная на сторону `a`.
* **Возвращаемое значение:**
  * `float` - площадь треугольника.
* **Пример вызова:**
  ```python
  import triangle

  s = triangle.area(4, 5)
  print(s)  # Выведет: 10.0
  ```

#### `perimeter(a, b, c)`
* **Описание:** Вычисляет периметр треугольника по трем сторонам.
* **Математическая формула:** $P = a + b + c$
* **Параметры:**
  * `a` (`int` | `float`) - длина первой стороны.
  * `b` (`int` | `float`) - длина второй стороны.
  * `c` (`int` | `float`) - длина третьей стороны.
* **Возвращаемое значение:**
  * `int` | `float` - периметр треугольника.
* **Пример вызова:**
  ```python
  import triangle

  p = triangle.perimeter(3, 4, 5)
  print(p)  # Выведет: 12
  ```
